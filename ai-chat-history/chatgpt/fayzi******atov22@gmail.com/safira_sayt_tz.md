# 🚀 Safira.uz — Enterprise Hybrid Microservices Platform
### *Talabalar va Xizmat ko'rsatuvchilarni birlashtiruvchi SaaS Agregator Platformasi*
## 📌 1. Loyiha Haqida (Project Overview)
**Safira.uz** — Onlayn va oflayn xizmatlarni (Davlat xizmatlari, ishlab chiqarish, rekonstruksiya, ijtimoiy xizmatlar va h.k.) hududlar (viloyatlar) kesimida guruhlovchi, talabalar va taklif beruvchilarni bitta muhitda jamlovchi murakkab platforma. ## 🏗️ 2. Tizim Arxitekturasi (System Architecture)
Loyiha bir nechta texnologiyalarni birlashtirgan **Gibrid Mikroservis (Microservices)** arxitekturasiga asoslangan.
```
[ Next.js Frontend ] (Next-Auth + HttpOnly Cookies)
         │
         ├─── API Request ───> [ NestJS Microservice ] (Auth, Chat/WebSockets, Upload)
         │                               │
         └─── API Request ───> [ PHP Server ] (Core Business Logic / CRUD)
                                         │
                                [ Python Bot ] (Telegram Automation & Notifications)

```
### 🛰️ Servislar va Ularning Vazifalari:
 1. **Next.js (Frontend - Client & SSR):** * Asosiy foydalanuvchi interfeysi (UI), SEO optimizatsiyasi.
   * **Mas'uliyati:** Login/Register interfeysi, filtrlar paneli, dinamik tavsiyalar sahifasi, redirekt va sahifalar xavfsizligi (middleware.js).
 2. **NestJS (Microservice - Core Engine):**
   * **Auth Service:** JWT Access/Refresh tokenlarni generatsiya qilish va xavfsizlik.
   * **Chat Service:** Real-time (lahzalik) xabarlashuv tizimi (**WebSockets / Socket.io**).
   * **Upload Service:** Ogʻir fayllar va rasmlarni yuklash (Stream'lar bilan ishlash).
 3. **PHP Server (Core Backend):**
   * **CRUD & Business Logic:** Servislar bazasi bilan ishlash, kategoriyalarni guruhlash, viloyatlar boʻyicha qidiruv tizimi.
 4. **Python Bot (Automation):**
   * Telegram orqali bildirishnomalar (notifications) yuborish, yangi qoʻshilgan servislarni guruhlarda avtomat reklama qilish.
## 🔐 3. Autentifikatsiya va Xavfsizlik Zanjiri (Auth Flow)
 1. Foydalanuvchi **Next.js** sahifasida ma'lumotlarini kiritadi.
 2. Next.js bu ma'lumotlarni **NestJS Auth** servisiga yuboradi.
 3. NestJS parolni tekshirib, **JWT Access & Refresh Token** qaytaradi.
 4. Next.js ushbu tokenlarni XSS hujumlaridan himoyalangan, xavfsiz **HttpOnly Cookie** ichida saqlaydi.
 5. Keyingi barcha soʻrovlarda (PHP yoki NestJS'ga) Next.js ushbu tokenni Header'da (Authorization: Bearer <token>) yuboradi.
 6. **PHP va NestJS** bitta umumiy maxfiy kalit (JWT_SECRET_KEY) orqali tokenni mustaqil ravishda shifrdan ochadi (verify qiladi) va foydalanuvchini taniydi.

//  secret and  ecpiresin 
export const getJwtOptions = (config: ConfigService, type: jwtTokenType = jwtTokenTypeEnum.ACCESS) => {
    const options: JwtSignOptions = {
        secret: config.get<string>(`JWT_${type.toLocaleUpperCase()}_SECRET`),
        expiresIn: config.get<string>(`JWT_${type.toLocaleUpperCase()}_EXPIRES_IN`)
    }
    return options
}

// token generate function
export const getToken = async (
    jwtService: JwtService,
    payload: JwtPayload | JwtVerfyPayload,
    config: ConfigService,
    type: jwtTokenType = jwtTokenTypeEnum.ACCESS
) => {
    const token = await jwtService.signAsync(payload, getJwtOptions(config, type))
    return token
}

@Injectable()
export class JwtSubService {
    constructor(
        private readonly jwtService : JwtService,
        private readonly configService : ConfigService,
    ){}

    async getAccessToken(user : User){
        const { id, role } = user;
        const token = await getToken(
            this.jwtService,
            {id, role},
            this.configService
        );
        return token;
    }
    async getRefreshToken(user : User){
        const { id, role } = user;
        const token = await getToken(
            this.jwtService,
            {id,role},
            this.configService,jwtTokenTypeEnum.REFRESH
        );
        return token;
    }
    async getVerfyToken(req : Request,data : {email:string,code:number}){
        const {ip,agent} = req['device']
        const token = await getToken(
            this.jwtService,
            {...data,ip,agent},
            this.configService,jwtTokenTypeEnum.VERIFY
        );
        return token;
    }
    async verifyToken<T>(token:string,type : jwtTokenType) : Promise<T>{
        const result : T = await decodeToken<T>(this.jwtService,token,this.configService,type)
        return result
    }
}
